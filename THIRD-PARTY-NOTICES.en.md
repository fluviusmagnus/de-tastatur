## Windows: German Extended E1 / E2

- Drivers: `KBDGRE1.DLL` (E1), `KBDGRE2.DLL` (E2)
- KLID: `00020407` for E1, `00030407` for E2
- Pages: <https://kbdlayout.info/KBDGRE1/>, <https://kbdlayout.info/KBDGRE2/>
- Local location: `references/windows/`

These files are **descriptive snapshots generated by kbdlayout.info from
Microsoft's publicly documented driver tables**, not code extracted from Windows
or from driver binaries. No DLL was downloaded or executed. They are used to
check key positions, dead-key state machines and extended-selection behaviour,
and to make generation reproducible.

Please note:

- The files retain their original generated content and the copyright notices
  contained in them. For example, `kbdgre2.klc` contains
  `© Microsoft Corporation. All rights reserved.`
- This project **grants no license to these files** and claims no copyright in them.
- If you are a rights holder and believe these snapshots should not be
  redistributed, please open an issue. I will remove the relevant files and
  switch to downloading and verifying them at build time.
- These materials describe keyboard-layout behaviour only; they contain no
  Microsoft driver code, signatures or runtime components.

Download URLs and snapshot checksums are listed in
[`references/README.md`](references/README.md) (currently in Chinese) and
[`references/SHA256SUMS`](references/SHA256SUMS).
